# Organização de Estrutura de Arquivos

Projeto desenvolvido para a disciplina **Organização de Estrutura de Arquivos**.

## 📂 Estrutura de Pastas

1. **Busca Binária - Arquivo CEP**
2. **Índice Ordenado CEP**
3. **Ordenação Externa - Diversos Blocos**
4. **Processamento de CSV / Covid**
5. **Junção Bolsa Família - Interseção com HASH Join** *(em desenvolvimento)*
6. **CEP indexado com Árvore B - ISAM** *(em desenvolvimento)*
7. **Pasta de dados**

# 📚 Fonte dos Dados

Os dados de COVID-19 utilizados neste projeto foram obtidos do repositório público do **Our World in Data (OWID)**:

- Our World in Data. *Coronavirus Pandemic (COVID-19)*. Disponível em: [https://ourworldindata.org/coronavirus](https://ourworldindata.org/coronavirus)  
- Dataset completo: [https://github.com/owid/covid-19-data](https://github.com/owid/covid-19-data)

Este dataset reúne informações globais sobre casos, mortes, vacinação e outros indicadores relacionados à pandemia, cobrindo a maioria dos países e regiões do mundo.
